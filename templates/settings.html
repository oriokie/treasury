Setup
1. In Telegram, message @BotFather → /newbot, and paste the token above.
2. Turn the bot on and save.
3. Either run the bot from a server with python manage.py telegram_bot,
  or, if this site has a public HTTPS address, register a webhook (replace HOST and TOKEN):
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<HOST>/api/telegram/webhook/<TOKEN>/
4. Open your bot in Telegram, send any message, and enter your PIN when prompted.

Check for & install updates
How updates work. Updates are never forced and never applied automatically. When a new version is published you'll see an "Update available" banner. Click Check for & install updates above and then Update now — the app backs up your database, fetches the new code, applies any database changes, and reloads itself, all from this screen. Nothing changes until you click. (Server admins can alternatively run ./update.sh; see DEPLOYMENT.md.)
Backup & data export

Keep your own copies of the church's financial data. Both downloads are generated on demand — nothing is stored on the server.

⤓ Download full backup (.sqlite3) ⤓ Export all data (Excel)
The full backup is a complete, restorable snapshot of the database — keep it somewhere safe (it contains all financial records). To restore, replace the app's database file with a backup and restart.
The Excel export is a multi-sheet workbook (members, transactions, expenses, funds, reconciliations) for analysis or archival — it can't be restored back into the app.
