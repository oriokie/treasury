Safe to repeat. Nothing here posts to the ledger.
← Register
This is not the ledger import. That one turns bank rows into transactions — it allocates money and posts to funds, so importing the same month twice is something to be careful about. This import does none of that: it only records what the bank said. Every line is keyed on the bank's own reference, so re-importing an overlapping period — or the same file twice — adds only what is genuinely new. Importing from January every month is a perfectly sensible thing to do here.
