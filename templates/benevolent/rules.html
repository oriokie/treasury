Contribution narration rules

What a member types on a phone keypad, and which scheme it means
Test a narration ← Intake

These use the same match types and the same normalised text as the main allocation rules — a companion to that engine, not a second parser. A rule says which scheme the money is for. It does not say which member: the allocator works that out from far better evidence (phone numbers, membership numbers, case references) than a keyword could ever give.
