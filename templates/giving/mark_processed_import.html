Mark bank entries as manual receipts

For gifts already receipted on paper — kept out of receipting, no system envelope created
Use this when members have hand-written envelopes (receipted on paper) for money that also shows on the bank statement. Marking those bank entries as manual receipts keeps them out of the review queue and the "receipt bank giving" pull so they aren't receipted twice — and no system envelope is created (they were receipted by hand). This is reversible: untick "manual receipt" on an entry to make it eligible for a system receipt later.
  1. Download the template — two columns: reference and amount.
  2. Fill one row per envelope: the reference (M-Pesa code or bank reference) and the amount.
  3. Upload it. The reference finds the bank entry; the amount confirms it's the right record. A mismatch is reported, not applied.
