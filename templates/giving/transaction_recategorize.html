Use this when entries were auto-allocated to the wrong fund. Paste the reference number of each gift — the M-Pesa code, the core ref, or the bank receipt — choose the fund they should be in, and you'll see a confirmation list before anything moves. Amounts, dates and payers stay as they are. The fund changes, the status becomes Manual, and the change is kept in each entry's audit history.
Paste each gift's own reference, not the allocation word (such as “tithe”) that many unrelated gifts share. A split gift moves as a whole, so one part is not left behind. Entries that are already receipted, or that fall in a locked month, are left unchanged. Afterwards, correct the allocation rule so the next import does not repeat the mistake.
