How it works
  1. Download the current expenses as a spreadsheet.
  2. Edit the “New category” column — type a category label (e.g. Transport) or its code — and/or the “New type” column with Capital or Recurrent. The other columns are there for reference and are ignored on import.
  3. Upload the edited file. Only the category and expenditure type are updated, matched by the expense ID; amounts, dates and descriptions are never touched.
